# ScanDeepFake: Professional AI Forensic & Deepfake Detector

ScanDeepFake is a state-of-the-art web application designed to safeguard digital truth by verifying media authenticity. Utilizing advanced vision transformers and frequency domain analysis, it detects **AI-generated images**, **face swaps**, and **deepfake videos** with high precision.

## 🚀 Access Points

- **Official Web App:** [https://scandeepfake.web.app](https://scandeepfake.web.app) (Fast Edge Delivery)
- **Hugging Face Space:** [ScanDeepFake Scanner](https://huggingface.co/spaces/gundkatira/scandeepfake-scanner) (Docker Analysis Engine)

## 🛠 Key Features

- **Deepfake Detection Online:** Instant verification of synthetic media.
- **AI Face Swap Checker:** Specialized neural scan for facial inconsistencies.
- **Forensic Reports:** In-depth breakdown of pixel artifacts and frequency spikes.
- **Privacy First:** Localized processing and zero-retention policy.
